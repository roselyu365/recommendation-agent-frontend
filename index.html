01 / FIND YOUR NEXT READ

从书架出发，
走进一次阅读。

不必先想好书名。说说你想获得什么，找到感兴趣的书，再把阅读中生出的好奇留下来。

一段选书对话 · 文案示例

“读点别的，换换心情。”

理解，那就让我们暂时忘记秋招的烦恼，去书中看看有趣的日常与自然的风光。

02 / STAY WITH A SENTENCE

不只是解释字句，
也打开另一层风景。

以《小径分岔的花园》为例。我们希望陪读带来的，是书外背景与文学联想，而不是冗长的逐字分析。

你选中的一段

我给了他们一枚钱币（我身上最后的一枚），下了几级石阶，走上那条僻静的路。路缓缓下坡。是一条泥土路，两旁都是树，枝桠在上空相接，低而圆的月亮仿佛在陪伴我走。—— 博尔赫斯《小径分岔的花园》

陪读示例

体验演示

看懂这段

从原文出发，补充有依据的背景与文学联想。只谈当前允许的内容，不预告后面的情节。

留下批注

记下自己的理解，而不是只留下 AI 的答案。读过一遍的文字，也可以保留不同的感受。

自由提问

由你决定往哪里聊：一个意象、一处典故，或一句没想明白的话。

03 / SYSTEM ARCHITECTURE

底层架构

固定工作流承载主链路，模型完成局部判断；检索、记忆与输出校验各司其职。

固定编排 + 局部模型决策Recommend Agent · Reader Agent · Shared Memory
01 / WORKFLOW

节点编排

区分决策点、执行点与人工确认点。模型判断意图与适配；规则处理约束、路由与提交检查，工具执行取数与检索。

输入输出契约 · 超时降级 · 节点追踪
主链路已实现；完整编排持续接入
02 / RETRIEVAL

检索增强 · RAG

从选段提取检索线索，路由到书内上下文或书外背景。材料先核对来源与阅读范围，再生成并检查回答，防止引入未读情节。

选段 → 材料检索 → 证据审核 → 生成校验
当前采用选段 + 预审背景；多源检索待接入
03 / RECOMMENDATION

场景推荐

将阅读目的与时间、精力等约束转成查询方向。关键词与语义两路召回，经场景适配判断，再结合偏好、反馈和多样性组合书目。

召回 → 适配 → 排序 → 书架内外组合
适配与组合已接入；双路召回已完成离线实验，待接业务链
04 / MEMORY

共享记忆

区分阅读事实、待确认推断与已确认偏好。按本轮相关性召回，保留来源、有效期与撤回状态；本轮明确需求优先。

信号提取 → 准入与合并 → 相关召回
已有记忆机制；微信读书数据整合中
当前实现范围
