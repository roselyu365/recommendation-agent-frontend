# 候选包材料与许可清单

本文件不是开源许可证。当前提供自用预览版源码与安装包，正式代码LICENSE尚未确定；不要将预览发布理解为已经授予任意再分发或商业使用许可。

| 材料 | 包含内容 | 边界 |
| --- | --- | --- |
| Python / JS / HTML / CSS | 本项目原型代码 | 待确认代码许可及依赖审查；不自动为其他来源材料授权 |
| 阅读花园插画 | 本项目生成的页面插画 JPG | 与代码许可分开说明；不包含第三方品牌插画 |
| book-profiles.json | 13本已有作品内容摘要、类型、未知项 | 从历史实验抽取中性描述；移除了个人书架关系、反馈、场景评分、排序和记录来源路径。不是新核验的全书资料 |
| card-materials.json | 三本书的简短引文、出处、简介、书封链接和阅读链接 | 保留引文出处；不包含书籍正文或下载后的书封。第三方引文/封面不因代码开源而变为自由素材，公开发行前仍需审核 |
| background.py | 两条事实转述和博物馆来源链接 | 只保留简短事实，不复制来源整页 |

包中不应出现：作者 Key、个人书架、阅读进度、笔记、浏览器资料、配对令牌、读书截图、模型实测日志或整本书。
构建使用固定白名单，不会复制整个 experiments 目录。正式发布前还需按实际压缩包核对，不以白名单存在替代安全检查。
