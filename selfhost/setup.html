把书架接过来，
把想法留下来。

完成下面几步，就能从自己的书架出发，
在微信读书网页版里使用陪读。

每个人使用自己的授权和独立 Chrome 资料夹。密钥只在本机配置，不在这里填写。

使用前，看看这里

正在检查本机连接…

  1. 01

    让本机服务运行起来 检查中

    这个页面能正常打开，说明本机入口可访问。终端窗口需要保持运行。

    python3 selfhost.py start
  2. 02

    配置你自己的两类授权

    在安装目录运行下面的命令。依次输入微信读书 Key、OpenAI API Key 和模型名称，密钥输入不回显。

    python3 selfhost.py init

    获取微信读书授权 ↗ · 模型调用费用由自己的 API 账号承担。

    微信读书：检查中模型：检查中

    “已配置”只表示本地存在授权，不代表已验证有效。已有配置不会覆盖；更新 Key 请在本机编辑对应授权文件。

  3. 03

    把插件装进桌面 Chrome 候选版 0.4.0

    手动打开 Chrome 的扩展管理页，开启开发者模式，加载安装目录下的 copy-event-probe 文件夹。更新已有插件时点击刷新，无需卸载，避免丢失本地批注。

    允许声明的单次剪贴板读取与本机连接权限；没有新增权限。手机版微信读书 App 暂不支持。

  4. 04

    批准本机连接 检查中

    在微信读书网页版选中一段，点击插件。面板中可检查连接；点击“连接本机”打开确认页。核对刚刚发起的扩展，再批准。

    批准不会自动发送原文。回到面板点击“看懂这段”或“发送问题”后，才调用模型。

  5. 05

    同步书架，开始阅读 检查中

    回到书架点击同步，用一个场景找书。打开微信读书后，选段一次点击陪读；原文可修改，批注在本机保存。

    去我的书架 ↗检查待批准的连接

想法留在自己的电脑里

在插件面板点击“我的批注”，可以按书名、原文和想法查找，导出 JSON 或 Markdown，也能删除单条或清空。批注管理不需要模型服务在线。

停止本机服务会断开配对、清空本次书架快照；重启后重新同步和连接。批注不会随服务重启消失。同一个 Chrome 资料夹的批注尚未按微信账号隔离。

撤销连接不会撤回已经发送给模型的请求。删除批注只影响本插件本机记录，不修改微信读书。

仅本地候选版 · 不自动验证授权，不自动发送选段
