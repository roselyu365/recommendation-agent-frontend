  1. 01

    下载并解压

    点击上方下载按钮，将 ZIP 解压到固定位置。里面的 shu-reader 就是完整程序，不需要另装 Node 或其他项目。

    没有 Python？先从 Python 官网安装 3.10 或更新版本。不要直接在 ZIP 预览中运行。

  2. 02

    启动，在本机输入授权

    打开解压目录里的 start.command。首次启动会在终端中询问两个 Key 和模型名称，之后打开本机引导页。

    打开解压目录里的 start.bat。首次启动会在终端中询问两个 Key 和模型名称，之后打开本机引导页。

    Windows 启动入口已提供，尚未完成实机验收；遇到问题请参考终端方式。

    在解压后的 shu-reader 文件夹打开终端，运行：

    python3 launch.py　Windows 可用 py -3 launch.py

    密钥输入不回显，只存本机；不要填在公开网页或发给项目作者。ChatGPT 订阅不能代替模型 API 授权。启动后保持终端窗口运行；若系统阻止脚本，不要关闭系统安全保护，可先检查源码并使用终端方式。

  3. 03

    把陪读插件装进 Chrome

    手动打开 chrome://extensions，开启开发者模式，点击“加载已解压的扩展程序”，选择解压目录里的 copy-event-probe 文件夹。名称应为“SHU 选段陪读”，版本 0.4.0。

    这是未上架商店的预览插件。已有旧版请刷新原安装目录，不要卸载，以免丢失本机批注。

  4. 04

    同步自己的书架，读到心动处

    本机引导页会显示配置与连接状态。进入书架后点击同步，打开一本书到微信读书网页版。

    拖选原文，让“复制”菜单出现，点击一次插件。原文可以修改；点击“连接本机”并在确认页批准后，回到面板使用“看懂这段／批注／自由提问”。

    批准连接不会自动发送原文。只有主动点击模型功能才发送当前选段；“我的批注”可以查看、导出和删除本机记录。

先了解一点边界

这是可以安装的自用预览版，不是手机微信读书 App 内嵌插件。书架读取来自你的授权；当前推荐采用有限书目资料，陪读也仍有出错风险。第二位用户从零安装的真实授权闭环尚未完成验收。
